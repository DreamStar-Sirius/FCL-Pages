# 配置说明

FCL 的配置文件位于程序目录下的 `FCL/` 文件夹中：

```text
FCL/
├── Settings.ini          # 启动器设置
├── LatestVersion.ini     # 最近启动的游戏信息
├── Jvm.ini               # JVM 参数
└── Account.ini           # 账户信息（务必保密）
```

## 常见配置项

### 内存分配

在设置页面可调整分配给游戏的内存大小，建议保留系统至少 4GB 可用内存。

### Java 路径

FCL 会自动下载 Java 运行时，通常无需手动配置。如需使用自定义版本，可在设置中指定路径。

### 下载源

FCL 使用多源共下策略（包括官方源与镜像源 BCMLAPI），保障下载速度。目前无法自主选择使用哪个源进行下载。

### 启动参数

支持自定义 JVM 参数，高级用户可优化游戏性能。

## 警告

- `Settings.ini` 比较脆弱，不明白含义时不要随意修改，否则可能导致主程序报错打不开。
- `Account.ini` 包含账户信息，**千万不要对外泄露**，尤其是使用正版账号的用户。
