# 快速开始

只需几步即可开始使用 FCL 启动 Minecraft。

## 1. 下载安装包

前往首页点击“立即下载”，获取最新版本的安装包（`.exe` 格式）。

## 2. 运行安装

运行下载的安装程序，按向导完成安装。建议安装到不含中文的路径；若 Minecraft 路径保持默认（`.minecraft`），同样不能包含中文。

## 3. 运行启动器

双击桌面上的 `快捷方式·FCL`，首次启动会自动初始化环境。

## 4. 开始游戏

选择游戏版本，完成下载、部署和设置后，点击启动即可游玩。
