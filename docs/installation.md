# 安装指南

## 系统要求

- Windows 10/11 x64 或更高版本
- 6GB 以上可用内存
- 500MB 可用磁盘空间（不含游戏本体）
- 运行库不做额外要求，安装程序会自动安装

## 详细步骤

1. 点击首页的“立即下载”按钮获取最新版本。
2. 运行下载的 `.exe` 文件进行安装。
3. 右键点击桌面上的 `快捷方式·FCL`，选择“以管理员身份运行”（推荐）。
4. 按照安装向导完成初始设置。

## 卸载

在系统设置中卸载 Furnace Craft Launcher 即可。卸载不会删除已下载的 Minecraft 游戏文件。
