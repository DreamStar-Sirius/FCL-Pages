# 概述

Furnace Craft Launcher（FCL）是一款现代化、功能全面的 Minecraft 启动器，致力于为玩家提供简单易用、高性能的游戏启动体验。

## 为什么选择 FCL

- **轻量快速**：极速启动，资源占用较低。
- **安全可靠**：开源透明，数据加密存储。
- **全球加速**：集成多个国际镜像源，下载速度更快。
- **一键部署**：自动下载并配置 Minecraft 运行环境。
- **安全登录**：支持微软账户登录，账户信息加密存储。

## 适用平台

FCL 主要支持 **Windows 10/11 x64** 平台，同时通过 GitHub Releases 和蓝奏云提供多渠道下载。
