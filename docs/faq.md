# 常见问题

## 启动器无法打开？

请确保系统为 Windows 10/11 x64，且已安装最新的系统更新。如仍无法打开，请尝试以管理员身份运行。

## 下载速度很慢怎么办？

有些很小的资源下载速度本来就会比较慢；也可能是只使用了一个源（这意味着其他源没找到这些资源，这不是 Bug）。

## 游戏闪退或报错？

请检查：

1. 分配的内存是否足够；
2. 游戏版本与已安装的模组是否兼容；
3. JVM 参数是否正确。

如问题持续，请通过反馈页面提交日志。

## 如何更新启动器？

启动器会自动检查更新，也可以在首页手动下载最新版本覆盖安装。建议保持自动更新开启。

## 支持哪些游戏版本？

支持所有正式版 Minecraft，包括最新版本、快照版、经典旧版和愚人节版本。

## 内测版如何下载？

FCL 程序内有“成为内测员”选项，当有内测版发布时即可点击下载。任何人都可以参与内测，无需申请。

## 如何参与 FCL 开发？

请联系作者申请加入开发团队。注意：FCL 的任何分支（例如社区版）必须向作者申请权限后才可进行开发。
